## 1. Why this note exists

The repository previously contained incompatible historical 250k and 1M result sets. Those legacy records are retained for traceability only and must not be mixed with the final release benchmark. The accepted comparison is the deduplicated release run in `outputs/release/release_summary.json`: 5 models × 3 feature groups × 3 nested budgets (250k, 1M and 2.5M), one seed (42), one runner and one split protocol. All 45 result rows are labelled by budget and feature group in Section 7.1 of the final report. The historical `outputs/full_colab_results.json` values are not part of the release comparison.

## 3. What stands out

1. **The clean Logistic Regression rerun is consistent across sample sizes.** The 250k all-features test ROC-AUC is 0.6854 and the 1M value is 0.6834. The original 250k value of 0.8369 was fabricated placeholder data and is excluded. XGBoost and MLP comparisons remain separate by sample size and run configuration. <!-- allow-metric -->
2. **The original Logistic Regression discrepancy is resolved.** The corrected 250k clean rerun and 1M result are close. The previous apparent gap was caused by the invalid 250k placeholder.
3. **The neural result remains under review.** The current 250k compact-MLP all-feature artifact reports test ROC-AUC 0.8121, while the separate 1M wide-MLP record reports 0.8399. These are different configurations and are not a direct comparison. The 250k MLP artifact remains provisional until independent reproduction and the release decision are recorded. T1 split disjointness alone does not establish independent MLP reproducibility. <!-- allow-metric -->
4. **Training time was corrected.** T6 restored per-model timings: Logistic Regression 2.6 seconds, XGBoost 35.1 seconds and MLP 395.1 seconds.
5. **Feature names are corrected.** The current 250k metrics files use the canonical HIGGS feature names; BUG-019 was verified fixed on 2026-11-13.
6. **Generated inputs and model weights are not committed.** The raw HIGGS source can be downloaded and the 250k/1M samples regenerated using the documented scripts and manifests. Saved model weights are excluded; model artifacts must be regenerated by running the training workflows.

## 5. Release decisions recorded (15 November 2026)

1. The headline comparison is the full 250k / 1M / 2.5M release matrix, with each budget and feature group shown separately.
2. All 45 runs use the same release runner, seed 42, deduplicated source data and nested samples; the historical notebook benchmark is retained for traceability, not mixed into the release table.
3. XGBoost remains in scope as the tuned classical baseline.
4. The release summary and per-run metrics are the numeric source of truth. No single score should replace the comparison table.

## 6. What may and may not be written until this is closed

**May be written now, with the protocol stated:**
- The method, the data card, the split protocol and the feature groups.
- Each result table, labelled with the sample size and the protocol it came from.
- Limitations, including this inconsistency.

**Still must not be claimed:**
- Multi-seed robustness or statistical significance: only seed 42 is reported.
- Real detector performance, physical probabilities or discovery significance.
- A validated operating-point threshold / signal-efficiency / background-rejection result from the release artifacts, because those values are not serialized there.
- Comparisons that combine the legacy `full_colab_results.json` pipeline with the final release benchmark.

## Release closure (15 November 2026, Krishna)

The outstanding tests were closed by one run of `scripts/release_benchmark.py` on Kaggle (Tesla T4) against the full UCI file. Evidence: `outputs/release/release_summary.json` and the per-run `metrics.json` files under `outputs/release/<budget>/`.

| Test | Status | Evidence |
|---|---|---|
| T1 split integrity | **PASS** | 278,698 duplicate events removed before sampling. At 250k, 1M and 2.5M the split indices are disjoint, cover every row, and share **0** events between train and test. The first release run, before deduplication, found 44 (250k) and 454 (1M) shared events, which is why deduplication was added. |
| T4 MLP reproduction | **PASS** | Two CPU trainings of the compact MLP with seed 42 give identical test probabilities (max difference 0.0). |
| T5 like-for-like budgets | **PASS** | All 45 runs (5 models × 3 feature groups × 3 budgets) come from one script, one seed and nested samples, so the budgets are directly comparable. |
| T7 accuracy/threshold | **PASS** | Accuracy at threshold 0.5 is recomputed from each run's saved `test_predictions.csv` by `scripts/build_final_deliverables.py`. |

**Headline decision.** The report leads with the full comparison table rather than one score. The supported claim is that, with the same split and seed, deep networks (5×300 MLP and residual MLP) beat a validation-tuned XGBoost at every budget, with the gap growing from 250k to 2.5M, and that on low-level features alone they beat XGBoost given all 28 features. Earlier figures (the 0.9406 MLP draft, the 412.03 s copied runtime in `full_colab_results.json`) are superseded and are not quoted anywhere as results.
